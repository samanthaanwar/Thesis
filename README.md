# Texas Power Crisis: Estimating ERCOT’s Performance with Stronger Regional Interconnections
### Sam Anwar | Columbia University in the City of New York
### Graduate Thesis for M.A. Quantitative Methods in the Social Sciences
### May 2025

This repository includes the Python code and interactive plots used for my graduate thesis project.

`Thesis_FinalNotebook.ipynb` contains all code. Datasets are either found in the `data` folder or in the notebook as API endpoints. `plots` folder contains HTML output of plots.

The final project can be found here: https://samanwar.notion.site/thesis
